# meet-wild — Wild 선생님께 면담 요청하기

학생이 "선생님이랑 얘기하고 싶다"고 느낀 순간을 **면담 요청 한 건**으로 정리해 보낸다.
학생은 정해진 시간 중 하나를 고르고, Wild 선생님이 답장으로 확정한다.

**언어 규칙**: 학생이 쓰는 언어로 대화하고, 요청 본문도 학생의 언어로 쓴다. 호칭은 "Wild 선생님"이다. 영어 본문은 "Dear Wild,"로 시작한다.

## 면담 규칙 (Wild 선생님이 정한 기준)

| 규칙 | 내용 |
|---|---|
| 날짜 | **수업이 있는 날** |
| 시간 | **12:00 / 12:30 / 18:00** 중 하나 (Wild 선생님 시간대 기준) |
| 길이 | 20분 |
| 요청 시점 | 면담 시각보다 **최소 6시간 전** |
| 확정 | Wild 선생님의 **답장**으로 확정. 같은 시간에 요청이 겹치면 선생님이 조정한다 |

---

## 시작 방식: 요청과 제안

| 방식 | 조건 | 처음 행동 |
|---|---|---|
| **요청** | 학생이 Wild/선생님과 면담·상담을 원한다고 말함 | 바로 워크플로 1단계 |
| **제안** | 학생이 요청하지는 않았지만, 같은 대화에서 **방향성·진로·프로젝트 방향·학습 계획 같은 큰 고민**에 대해 막막함이나 좌절을 **두 번 이상** 표현함 | 한 번만 제안한다 |

제안 문구 (학생 언어로):

> 혼자 정리하기 쉽지 않은 고민 같아요. **Wild 선생님과 20분 면담을 요청해 볼까요?** 수업일 12:00·12:30·18:00 중에 고를 수 있어요. 원하지 않으면 저랑 계속 이야기해요.

고민이 **특정 과제나 문제 하나**에 관한 것이라면 이 스킬이 아니라 **ask-wild(질문)** 를 제안한다.

- **한 번의 "막혔어", "어렵다"는 해당하지 않는다.** 그때는 Claude가 평소처럼 직접 돕는다.
- 제안하기 전에 학생이 원하는 도움(설명, 힌트, 함께 풀기)을 먼저 충분히 한다. 제안은 그 도움을 대신하는 것이 아니라 **추가 선택지**다.
- 제안은 **같은 대화에서 한 번만** 한다. 학생이 거절하거나 대답하지 않으면 다시 꺼내지 않는다.
- 학생의 감정을 진단하거나 단정하지 않는다("좌절하셨군요" 대신 "계속 막히는 것 같아요").
- 학생이 수락하면 1단계로 가되, **지금까지의 대화로 패킷 초안을 먼저 채워** 학생에게 묻는 질문을 줄인다.
- 자해·학대·위험 같은 **안전이 걱정되는 신호**가 보이면 제안보다 먼저, 지금 바로 도움받을 곳(보호자나 가까운 믿을 수 있는 어른, 지역 상담 전화, 위급하면 긴급 연락처)을 안내한다. 이 스킬은 긴급 연락 수단이 아니다.

## 불변 규칙

1. **학생의 명시적 승인 없이 아무것도 보내지 않는다.**
2. **확정을 약속하지 않는다.** "요청을 보냈고, 선생님이 답장으로 확정해 주신다"까지만 말한다.
3. **정해진 시간 밖의 시간을 후보로 만들지 않는다.** 날짜·시간·6시간 조건은 `slots.py`로 검증하고, 통과한 슬롯만 보낸다.
4. **학생의 캘린더에 일정을 만들지 않는다.** 확정 답장을 받은 뒤 학생이 원하면 그때 돕는다.
5. **민감한 사정은 메일에 쓰지 않도록 돕는다.** 개인적인 일이 목적이면 본문에는 "개인적인 일로 이야기를 나누고 싶습니다" 정도만 쓰고, 자세한 이야기는 만나서 하도록 제안한다.
6. 암호·복호화된 주소 취급 규칙은 ask-wild와 같다: 암호는 stdin으로만 넘기고, 주소를 대화에 불필요하게 노출하지 않는다.

## 안전 우선 규칙

학생이 자해, 학대, 폭력, 괴롭힘, 위험한 상황처럼 **안전이 걱정되는 내용**을 말하면 면담 요청보다 이것을 먼저 한다.

- 지금 바로 도움을 받을 수 있는 곳을 안내한다: 보호자나 가까운 믿을 수 있는 어른, 그 지역의 상담 전화, 위급하면 긴급 연락처.
- Wild 선생님의 면담은 정해진 시간에만 열리고 메일은 바로 확인되지 않을 수 있다는 점을 분명히 말한다. 이 스킬은 긴급 상황의 연락 수단이 아니다.
- 학생이 원하면 면담 요청은 함께 보내되, 본문에는 세부 내용 없이 "급하게 이야기 나누고 싶은 일이 있습니다"만 쓰도록 제안한다.

## 워크플로

### 1) 무엇을 이야기할지 짧게 정리

| 필드 | 내용 |
|---|---|
| `topic` | 무엇에 대해 이야기하고 싶은가 (한 구절) |
| `purpose` | 수업 내용 심화 / 과제·프로젝트 / 진로·진학 / 개인적인 일 / 기타 |
| `format` | 대면 / 온라인 / 상관없음 |
| `with` | 함께 오는 사람 (그룹 면담일 때만, 이름 대신 인원수도 가능) |
| `prep` | 미리 보여드릴 자료나 링크 (선택) |

이름과 소속 조는 `profile get`으로 먼저 확인한다(시리즈 공용 프로필). 이름이 없으면 미리보기 뒤의 **학생 안내** 한 번으로 묻고 `profile set --name "…" --team "…"`로 저장한다(소속 조가 없다고 하면 `--team` 없이 저장). **반은 묻지 않는다**(반 암호로 자동으로 정해진다).
면담까지 기다릴 필요 없는 **짧은 질문**이면 ask-wild가 더 빠르다고 알려준다.
20분보다 길게 필요하면 그 이유를 `prep`에 한 줄로 적게 하고, 시간은 정해진 슬롯 중에서 고르게 한다(연장 여부는 선생님이 답장에서 정한다).

### 2) 채널 설정 열기

**부록 A** 절차로 채널 설정을 연다. 대부분은 학생에게 묻지 않고 자동으로 열린다. 열리면 설정을 읽는다:

```bash
python3 <skill_dir>/scripts/wild_vault.py get --config <skill_dir>/config/channels.enc.json --skill meet-wild
```

`payload`에서 쓰는 값 (모두 선택):

| 키 | 뜻 | 없을 때 |
|---|---|---|
| `class_calendar_id` | Wild 선생님의 **공개 수업일 캘린더** ID. 캘린더의 일정 하나 = 수업일 하나 | `class_schedule`을 쓴다 |
| `class_schedule` | 예비용 수업일. 예: `{"weekdays": ["Tue","Thu"], "dates": [...], "exclude": [...]}` | 모든 날을 후보로 보여주고, 학생에게 **수업이 있는 날을 고르라고** 안내한다 |
| `meeting_times` | 면담 시각 목록 | `12:00, 12:30, 18:00` |
| `timezone` | Wild 선생님 시간대 | `Asia/Seoul` |

반 암호를 3회 틀리면 본문을 복사용으로 준다.

### 3) 날짜와 시간 고르기

학생의 시간대가 Wild 선생님 시간대와 다를 수 있으면 한 번 묻는다(예: 해외 체류 중). 후보는 **머릿속으로 계산하지 않고** 스크립트로 뽑는다.

**수업일 가져오기** (위에서부터 가능한 것 하나):

1. **공개 수업일 캘린더** (`class_calendar_id`가 있고, 학생의 Google Calendar 일정 조회 도구가 있을 때): 그 캘린더 ID로 **오늘부터 4주** 동안의 일정을 조회하고, 결과 JSON을 그대로 넘긴다. 학생에게 묻지 않는다. 캘린더는 수시로 바뀌므로 매번 새로 조회한다.

   ```bash
   python3 <skill_dir>/scripts/slots.py list --count 8 --events-stdin \
     [--times '<meeting_times>'] [--tz <timezone>] [--student-tz <학생 시간대>] <<'JSON'
   <Calendar 일정 조회 결과 JSON>
   JSON
   ```
   조회가 실패하거나(권한 오류 등), 응답의 `accessRole`이 `freeBusyReader`이면(캘린더가 '한가함/바쁨만' 공개라 일정을 읽을 수 없음) 2번으로 넘어간다.
2. **예비 수업일** (`class_schedule`이 있을 때): `--schedule '<class_schedule JSON>'`로 실행한다.
3. **둘 다 없을 때**: 옵션 없이 실행하고, `class_calendar_id`가 있으면 학생에게 공개 캘린더 링크 `https://calendar.google.com/calendar/embed?src=<class_calendar_id>`를 주며 "이 캘린더에서 수업일을 확인하고 골라 주세요"라고 안내한다.

1번을 쓸 수 없어 2·3번으로 넘어가면, **부록 B**에 따라 Google Calendar 연결을 안내한다.

출력의 `schedule_source`가 `calendar`, `vault`, `none` 중 무엇인지로 어느 경로를 썼는지 알 수 있다. `warning`이 있으면(캘린더에 앞으로의 수업일이 없음) 그대로 알리고 Wild 선생님께 문의하도록 안내한다.

출력의 `slots[].label`을 번호와 함께 보여주고 **하나를 고르게** 한다. 학생 시간대가 다르면 `student_local`도 함께 보여준다.
`schedule_configured`가 `false`이면 "이 중에서 **수업이 있는 날**을 골라 주세요"라고 덧붙인다.

학생이 목록에 없는 날짜나 시간을 말하면 같은 수업일 정보로 검사한다:

```bash
python3 <skill_dir>/scripts/slots.py check "YYYY-MM-DD HH:MM" [같은 옵션, 캘린더면 같은 JSON을 다시 stdin으로]
```

`valid`가 `false`이면 `problems`를 그대로 알리고 목록에서 다시 고르게 한다. **통과한 슬롯만** 다음 단계로 넘긴다.

### 4) 미리보기와 승인

```
제목: [meet-wild]<topic>-[<반 라벨>][<team>][<name>]

Wild 선생님, 안녕하세요. <name>입니다.
<topic>에 대해 이야기를 나누고 싶어 면담을 요청드립니다.

■ 희망 일시: <선택한 slot의 label>
■ 목적: <purpose>
■ 방식: <format>
(■ 함께 오는 사람: <with>)
(■ 미리 볼 자료 / 참고: <prep>)

가능 여부를 답장으로 알려주시면 감사하겠습니다.
— meet-wild로 정리해 보낸 요청입니다.
```

영어로 쓸 때는 `Requested time / Purpose / Format / Joining / Materials`를 쓴다.
제목 태그 `[meet-wild]`는 항상 유지한다.

**학생 안내 (짧게)**: 첫 미리보기에서 반 라벨·소속·이름이 아직 비어 있으면 빈칸 그대로 보여 주고, 필요한 것만 아래처럼 **한 번에** 묻는다(잠금 여부는 부록 A의 `status`·A-1로 먼저 확인해, 이미 열려 있으면 반 비밀키는 묻지 않는다). 이미 알고 있는 항목은 문장에서 뺀다.

> 제목의 빈칸을 채우려면 **반 비밀키**와 **이름**이 필요해요. 소속 조가 있으면 함께 알려 주세요(없으면 `[개인]`으로 표기돼요).

제목이 어떻게 만들어지는지(반 라벨, 슬롯, 자동 입력 등)는 설명하지 않는다. 학생이 물을 때만 답한다.

### 5) 채널 생성과 전송

```bash
python3 <skill_dir>/scripts/compose.py --config <skill_dir>/config/channels.enc.json --skill meet-wild <<'JSON'
{"subject": "[meet-wild] <topic>", "body": "<미리보기 본문>",
 "fields": {"name": "…", "team": "<소속, 없으면 생략>", "topic": "…",
            "message": "<purpose> · <format>",
            "when": "<선택한 slot의 label>",
            "details": "<with> / <prep>", "link": "<prep 링크가 있으면>"}}
JSON
```

| 순서 | 조건 | 행동 |
|---|---|---|
| ① 메일 커넥터 | 학생의 메일 발송 도구가 있음 | 발송. 초안 도구만 있으면 초안을 만들고 [보내기]를 안내 |
| ② Google Form | ①이 불가하고 `form_url`이 있음 | 미리 채워진 링크 제시 → [제출]만 누르도록 안내 |
| ③ mailto | ①②가 불가 | 링크와 함께 본문 전체를 복사용으로 제공 |

①을 쓸 수 없어 ②·③으로 넘어가면, **부록 B**에 따라 Gmail 연결을 한 번 안내한다.

**반 라벨과 소속**: 메일·폼·mailto에는 `compose.py` 출력의 `subject`·`body`를 **그대로** 쓴다. `compose.py`에는 제목을 `[<skill>] <주제>`까지만 넘기면, 반 라벨·소속(`fields.team`)·**학생 이름**(`fields.name`)이 자동으로 붙어 `[<skill>]<주제>-[<반 라벨>][<소속>][<학생 이름>]` 형태가 된다(소속 조가 없으면 `[개인]`). 반은 학생이 입력한 반 암호의 슬롯 라벨이므로 **학생에게 묻거나 제목에 따로 적지 않는다.** 본문 끝에는 `(반: <반 라벨> · 소속: <소속 또는 개인>)`, 폼의 Class 칸에는 `<반 라벨> · <소속>`이 들어간다. 그래서 `fields.name`은 반드시 채운다(프로필 이름). 미리보기에서도 이 제목 그대로 보여준다.

### 6) 마무리

- 어느 채널로 보냈는지, 요청한 일시와 함께 한 줄로 알린다.
- "Wild 선생님이 답장으로 확정해 주시면 그때 면담이 잡혀요. 같은 시간에 다른 요청이 있으면 선생님이 다른 시간을 제안하실 수 있어요."
- 면담 전에 생각을 정리해 두면 좋은 질문 1–2개를 제안해도 된다.

## 문제 해결

| 증상 | 조치 |
|---|---|
| 학생이 정해진 시간 밖(예: 15:00)을 원함 | 규칙을 설명하고 목록에서 고르게 한다. 짧은 질문이면 ask-wild를, 안전 문제면 안전 우선 규칙을 따른다 |
| 6시간 안의 면담을 원함 | `slots.py check`의 안내 그대로 가장 빠른 가능한 시각부터 고르게 한다 |
| `python3` 실행 불가 | 복호화와 슬롯 검증 불가. 정해진 규칙(수업일 12:00/12:30/18:00, 6시간 전)을 알려주고 본문을 복사용으로 제공 |
| 종료코드 `3` | 부록 A의 접속 토큰 또는 반 암호 절차부터 다시 |
| 종료코드 `4` | 설정 파일 손상. 스킬 재설치를 안내하고 Wild 선생님께 알리도록 함 |

## 부록 A. 채널 설정 열기 (wild-series 공통)

모든 wild 스킬이 같은 절차를 쓴다. `<skill_dir>`는 이 SKILL.md가 있는 폴더, `<skill>`은 이 스킬의 이름(`meet-wild`)이다.

```bash
python3 <skill_dir>/scripts/wild_vault.py status --config <skill_dir>/config/channels.enc.json --skill meet-wild
```

| `state` | 행동 |
|---|---|
| `ok`, `refreshed`, `series` | 열림. 학생에게 묻지 않는다. (`series`는 다른 wild 스킬에서 이미 입력한 반 암호로 열린 것) |
| `no-cache` | **A-1** 학생용 접속 토큰을 스스로 찾는다 |
| `revoked` | "선생님이 이 반 암호의 사용을 중지하셨어요. 새 암호를 받아 입력해 주세요" → **A-2** |

### A-1. 학생용 접속 토큰 찾기 (학생에게 묻기 전에)

**학생용 접속 토큰**은 학생이 반 암호를 처음 입력했을 때 발급되는 한 줄이다: `WILD-TOKEN v3 <series-id> <token>`.
암호가 아니며, 선생님이 그 반 암호를 회수하면 자동으로 무효가 된다. 시리즈 전체(ask·meet·review·discuss·submit)에서 한 줄로 쓰인다.

아래 순서로 찾고, 처음 찾은 곳에서 멈춘다. **학생에게 아무것도 묻지 않는다.**

1. **현재 맥락**: 학생의 개인 선호 설정, Project 지침·파일, 이번 대화.
2. **과거 대화**: 과거 대화를 검색하는 도구가 있으면 `WILD-TOKEN`으로 검색한다.
3. **학생의 Google Drive**: Drive 검색 도구가 있으면 이름이 `wild-series 접속 토큰`인 파일을 찾아 내용을 읽는다.

찾은 줄(여러 개면 모두)을 stdin으로 넘긴다:

```bash
python3 <skill_dir>/scripts/wild_vault.py token import --config <skill_dir>/config/channels.enc.json --skill meet-wild <<'TOKEN'
WILD-TOKEN v3 <series-id> <token>
TOKEN
```

- 성공 → 열림. 학생에게 "저장된 접속 토큰으로 접속했어요" 한 줄만 알린다.
- 종료코드 `3`(회수됨/무효) 또는 아무 데서도 못 찾음 → **A-2**.

### A-2. 반 암호로 잠금 해제

미리보기의 **학생 안내**에서 이미 받았으면 다시 묻지 않는다. 아니면 학생에게 **"Wild 선생님께 받은 반 비밀키를 입력해 주세요"** 라고 요청하고, stdin으로 넘긴다 (명령행 인자로 넘기지 않는다):

```bash
python3 <skill_dir>/scripts/wild_vault.py unlock --config <skill_dir>/config/channels.enc.json --skill meet-wild <<'PW'
<학생이 입력한 반 암호>
PW
```

- 종료코드 `2`(wrong password): 다시 요청. **3회 실패** 시 중단하고 본문을 복사용으로 주며 "Wild 선생님께 암호를 다시 확인해 주세요"라고 안내.
- 성공 → 열림. 출력의 `"suggest_token": true`이면 **A-3**.
- 처음 연 경우 **부록 B**의 "처음 쓸 때" 안내를 한 번 한다.

### A-3. 접속 토큰 발급과 자동 보관

```bash
python3 <skill_dir>/scripts/wild_vault.py token export --config <skill_dir>/config/channels.enc.json --skill meet-wild
```

**학생이 직접 할 일을 최소화한다.** 아래 a는 항상 하고, b는 가능하면 하고, c는 a·b가 모두 불가능할 때만 한다.

| 방법 | 조건 | 행동 | 학생이 할 일 |
|---|---|---|---|
| **a. 대화 기록에 남기기** | 항상 | 발급된 토큰 줄을 이번 대화에 한 번 보여준다: "학생용 접속 토큰이 발급됐어요. 다음 대화에서는 제가 이 기록을 찾아 자동으로 접속할게요." | 없음 |
| **b. 학생 Drive에 저장** | Drive 파일 생성 도구가 있음 | "다음부터 확실하게 자동 접속되도록, 학생님 Google Drive에 토큰 파일을 저장해 둘까요?" **한 번** 묻고, 동의하면 `wild-series 접속 토큰` 문서를 만든다(내용: 토큰 줄 + 아래 설명). 같은 이름의 파일이 있으면 새로 만들지 않고 내용을 바꾼다. 공유 설정은 바꾸지 않는다 | "네" 한 번 |
| **c. 개인 선호에 붙여넣기** | a의 과거 대화 검색 도구도, b의 Drive 도구도 없음 | "설정 → 프로필 → 개인 선호에 아래 한 줄을 붙여 두면 다음부터 자동으로 접속돼요"라고 안내 | 붙여넣기 한 번 |

c로 넘어가면 **부록 B**에 따라 Google Drive 연결도 함께 안내한다(다음부터 토큰을 자동으로 보관·복원할 수 있다).

토큰 파일·안내에 함께 쓰는 설명: "학생용 접속 토큰입니다. 암호가 아니며, 선생님이 반 암호를 회수하면 자동으로 무효가 됩니다. 다른 사람과 공유하지 마세요."

- 학생이 b나 c를 거절하면 다시 묻지 않는다.
- A-1에서 이미 같은 시리즈의 유효한 토큰을 찾았다면 A-3은 생략한다.
- A-1에서 찾은 토큰이 회수되어 A-2로 새로 발급했다면, b로 저장해 둔 Drive 파일도 새 토큰으로 바꾼다.
- Claude Code(로컬)에서는 `~/.wild-skills` 캐시가 유지되므로 `suggest_token`이 `false`이고 A-3을 하지 않는다.

## 부록 B. 커넥터 연결 안내 (wild-series 공통)

커넥터가 연결돼 있으면 Claude가 확인과 처리를 직접 해서 **학생이 할 일이 줄고 결과가 정확해진다.** 그래서 이 스킬은 필요한 커넥터가 없으면 **항상 연결을 안내**한다.

| 커넥터 | 연결하면 자동으로 되는 것 | 쓰는 스킬 |
|---|---|---|
| **Gmail** | 요청·제출을 학생 메일로 바로 발송 (폼·복사 단계 없음) | 전체 |
| **Google Drive** | 공유 설정 검사, 선생님 계정 자동 공유, 접속 토큰 보관 | submit · review (토큰 보관은 전체) |
| **Google Calendar** | 수업일을 읽어 면담 가능한 시간만 보여줌 | meet |
| **GitHub** | 저장소 공개 여부 확인 | submit · review |

**언제 안내하나**

1. **처음 쓸 때**: 채널 설정을 연 직후(부록 A), 이 스킬이 쓰는 커넥터 중 지금 도구 목록에 없는 것을 한 번에 묶어 알린다.
2. **필요한 순간**: 커넥터가 없어 예비 경로(폼 링크, 학생 확인, 시크릿 창 확인, 수업일 직접 고르기 등)로 넘어갈 때, 그 자리에서 "이 단계는 ○○ 커넥터를 연결하면 자동으로 돼요"라고 한 줄로 알린다.

**규칙**

- 같은 대화에서 같은 커넥터는 **한 번만** 안내한다. 학생이 "나중에"라고 하면 그 대화에서는 다시 말하지 않는다.
- 안내 때문에 진행을 멈추지 않는다. **지금 일은 예비 경로로 계속**하고, 학생이 연결한 뒤 원하면 그 단계부터 다시 한다.
- 연결 여부는 Claude의 도구 목록으로 판단한다. 학생에게 "연결돼 있나요?"를 먼저 묻지 않는다.

**안내 문구** (학생 언어로)

> 이 단계는 **<커넥터>** 를 연결하면 제가 직접 확인해 드릴 수 있어요.
> Claude **설정 → 커넥터**에서 <커넥터>를 연결하고, 대화 입력창의 도구 메뉴에서 켜 두면 돼요. 지금은 다른 방법으로 계속할게요.
