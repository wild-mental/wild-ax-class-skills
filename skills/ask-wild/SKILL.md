# ask-wild — Wild에게 질문 남기기

학생이 막힌 순간을 **짧고 구조화된 질문 하나**로 정리해 Wild에게 전달한다.
목표는 "질문을 잘 쓰는 법을 몰라도 질문할 수 있게" 하는 것이다.

**언어 규칙**: 학생이 쓰는 언어로 대화하고, 질문 본문도 학생의 언어로 쓴다.
(국제학교 학생이면 영어, 한국어 화자면 한국어.)

---

## 시작 방식: 요청과 제안

| 방식 | 조건 | 처음 행동 |
|---|---|---|
| **요청** | 학생이 Wild/선생님께 질문을 보내 달라고 말함 | 바로 워크플로 1단계 |
| **제안** | 학생이 요청하지는 않았지만, 같은 대화에서 **특정 작업**(과제, 실습, 코드, 문제 풀이 등)에 대해 어려움이나 좌절을 **두 번 이상** 표현했거나, 같은 문제를 여러 번 시도해도 풀리지 않음 | 한 번만 제안한다 |

제안 문구 (학생 언어로):

> 이 부분이 계속 막히는 것 같아요. 지금까지 시도한 걸 정리해서 **Wild 선생님께 질문으로 보내 볼까요?** 원하지 않으면 저랑 계속 풀어 봐요.

고민이 특정 작업이 아니라 **방향성·진로·학습 계획 같은 큰 주제**라면 이 스킬이 아니라 **meet-wild(면담)** 를 제안한다.

- **한 번의 "막혔어", "어렵다"는 해당하지 않는다.** 그때는 Claude가 평소처럼 직접 돕는다.
- 제안하기 전에 학생이 원하는 도움(설명, 힌트, 함께 풀기)을 먼저 충분히 한다. 제안은 그 도움을 대신하는 것이 아니라 **추가 선택지**다.
- 제안은 **같은 대화에서 한 번만** 한다. 학생이 거절하거나 대답하지 않으면 다시 꺼내지 않는다.
- 학생의 감정을 진단하거나 단정하지 않는다("좌절하셨군요" 대신 "계속 막히는 것 같아요").
- 학생이 수락하면 1단계로 가되, **지금까지의 대화로 패킷 초안을 먼저 채워** 학생에게 묻는 질문을 줄인다.
- 자해·학대·위험 같은 **안전이 걱정되는 신호**가 보이면 제안보다 먼저, 지금 바로 도움받을 곳(보호자나 가까운 믿을 수 있는 어른, 지역 상담 전화, 위급하면 긴급 연락처)을 안내한다. 이 스킬은 긴급 연락 수단이 아니다.

## 불변 규칙 (어떤 경우에도)

1. **학생의 명시적 승인 없이 아무것도 보내지 않는다.** 미리보기 → "보내도 될까요?" → 승인 후에만 전송.
2. **원문 대화를 그대로 보내지 않는다.** 아래 패킷 필드만 요약해서 보낸다.
3. **보내지 않는 것**: 학생 본인 이름·소속 외의 개인정보, 다른 학생 정보, 비밀번호·토큰, 건강·가정사 등 민감 정보, 대화 전문. 학생이 직접 넣겠다고 해도 민감 정보는 한 번 확인한다.
4. **암호 자체를 저장·출력·파일에 기록하지 않는다.** 암호는 `unlock` 명령의 stdin으로만 넘긴다. 학생에게 보관용으로 줄 수 있는 것은 학생용 접속 토큰뿐이다.
5. **복호화된 주소를 대화에 불필요하게 노출하지 않는다.** 전송 도구 호출이나 링크 안에만 쓴다.

## 워크플로

### 1) 질문 패킷 추출 (경량)

현재 대화에서 아래 필드를 뽑는다. 비어 있는 필드는 학생에게 **한 번에 묶어서** 짧게 묻는다(최대 2개 질문).

| 필드 | 내용 | 길이 |
|---|---|---|
| `topic` | 무엇에 관한 질문인가 | 한 구절 |
| `team` | 소속 조 (있을 때만, 없으면 `개인`, 프로필에서) | 한 구절 |
| `context` | 하려던 것 + 이미 시도한 것 | 1–3문장 |
| `stuck` | 정확히 어디서 막혔나 | 1–2문장 |
| `question` | Wild에게 묻는 질문 | 1–2문장, 물음표로 끝남 |
| `urgency` | 마감·급한 정도 (선택) | 한 구절 |

좋은 `question`의 기준: Wild가 이 메일 하나만 읽고 답할 수 있어야 한다.
"모르겠어요"가 아니라 "X를 했더니 Y가 나오는데, Z가 왜 그런지 궁금합니다" 형태로 다듬는다.
단, **학생이 말하지 않은 내용을 지어내지 않는다.**

이름과 소속 조는 `profile get`으로 먼저 확인한다(시리즈 공용 프로필). 이름이 없으면 미리보기 뒤의 **학생 안내** 한 번으로 묻고 `profile set --name "…" --team "…"`로 저장한다(소속 조가 없다고 하면 `--team` 없이 저장). **반은 묻지 않는다**(반 암호로 자동으로 정해진다).

### 2) 미리보기와 승인

아래 형식으로 보여주고 승인을 받는다. 학생이 고치면 반영 후 다시 보여준다.

```
제목: [ask-wild]<topic>-[<반 라벨>][<team>][<name>]

Wild 선생님, 안녕하세요. <name>입니다.

■ 주제: <topic>
■ 하려던 것 / 시도한 것: <context>
■ 막힌 지점: <stuck>
■ 질문: <question>
(■ 마감: <urgency>)

— ask-wild로 정리해 보낸 질문입니다.
```

영어로 쓸 때는 같은 구조로 `Topic / What I tried / Where I'm stuck / My question / Deadline` 을 쓴다.
제목 태그 `[ask-wild]` 는 Wild의 메일 필터용이므로 **항상 유지**한다.

**학생 안내 (짧게)**: 첫 미리보기에서 반 라벨·소속·이름이 아직 비어 있으면 빈칸 그대로 보여 주고, 필요한 것만 아래처럼 **한 번에** 묻는다(잠금 여부는 부록 A의 `status`·A-1로 먼저 확인해, 이미 열려 있으면 반 비밀키는 묻지 않는다). 이미 알고 있는 항목은 문장에서 뺀다.

> 제목의 빈칸을 채우려면 **반 비밀키**와 **이름**이 필요해요. 소속 조가 있으면 함께 알려 주세요(없으면 `[개인]`으로 표기돼요).

제목이 어떻게 만들어지는지(반 라벨, 슬롯, 자동 입력 등)는 설명하지 않는다. 학생이 물을 때만 답한다.

### 3) 채널 설정 열기

**부록 A** 절차로 채널 설정을 연다. 대부분은 학생에게 묻지 않고 자동으로 열린다.

- `placeholder`가 `true`이면 Wild 선생님이 아직 실제 주소를 설정하지 않은 상태다. 학생에게 알리고 질문 본문을 복사용으로 제공한 뒤 종료.

### 4) 채널 생성

승인된 패킷을 JSON으로 넘겨 세 채널을 한 번에 만든다:

```bash
python3 <skill_dir>/scripts/compose.py --config <skill_dir>/config/channels.enc.json --skill ask-wild <<'JSON'
{"subject": "[ask-wild] <topic>", "body": "<미리보기 본문>",
 "fields": {"name": "…", "team": "<소속, 없으면 생략>", "topic": "…", "message": "<question>", "details": "<context + stuck + urgency>"}}
JSON
```

출력: `email`, `form_url`, `mailto` (설정되지 않은 채널은 `null`), `notes`.
`fields`의 키는 시리즈 공용 폼 규약([FORM.md](../FORM.md))을 따르며, `skill`은 자동으로 채워진다.

### 5) 3단계 폴백 전송

| 순서 | 조건 | 행동 |
|---|---|---|
| **① 메일 커넥터** | 학생의 Gmail/메일 커넥터에 발송 도구가 있음 | `email.to/subject/body`로 발송. 발송 도구가 없고 초안 도구만 있으면 초안을 만들고 "메일함에서 [보내기]를 눌러 주세요"라고 안내. |
| **② Google Form** | ①이 불가하고 `form_url`이 있음 | 링크를 제시: "이 링크를 열면 질문이 채워져 있어요. [제출]만 눌러 주세요." |
| **③ mailto** | ①②가 불가하고 `mailto`가 있음 | 링크 제시 + 본문 전체를 복사용 코드블록으로 함께 제공 (`notes`에 truncated가 있으면 반드시). |
| 모두 불가 | — | 질문 본문을 복사용으로 주고, Wild에게 직접 전달하는 방법을 묻도록 안내. |

①을 쓸 수 없어 ②·③으로 넘어가면, **부록 B**에 따라 Gmail 연결을 한 번 안내한다.

**반 라벨과 소속**: 메일·폼·mailto에는 `compose.py` 출력의 `subject`·`body`를 **그대로** 쓴다. `compose.py`에는 제목을 `[<skill>] <주제>`까지만 넘기면, 반 라벨·소속(`fields.team`)·**학생 이름**(`fields.name`)이 자동으로 붙어 `[<skill>]<주제>-[<반 라벨>][<소속>][<학생 이름>]` 형태가 된다(소속 조가 없으면 `[개인]`). 반은 학생이 입력한 반 암호의 슬롯 라벨이므로 **학생에게 묻거나 제목에 따로 적지 않는다.** 본문 끝에는 `(반: <반 라벨> · 소속: <소속 또는 개인>)`, 폼의 Class 칸에는 `<반 라벨> · <소속>`이 들어간다. 그래서 `fields.name`은 반드시 채운다(프로필 이름). 미리보기에서도 이 제목 그대로 보여준다.

메일 커넥터가 연결돼 있는지 모르면 도구 목록에서 Gmail/메일 발송 도구를 먼저 찾아본다. 학생에게 "메일 연결돼 있나요?"를 묻는 것은 그 다음이다.

### 6) 마무리

- 어느 채널로 보냈는지 한 줄로 알린다.
- 메일·폼은 비동기라는 점을 짧게 알린다: "Wild 선생님이 확인하시면 답이 올 거예요."
- 기다리는 동안 학생이 스스로 더 시도해볼 수 있는 **다음 한 걸음** 하나를 제안해도 된다 (정답을 대신 풀어주지는 않는다).

## 문제 해결

| 증상 | 조치 |
|---|---|
| `python3` 실행 불가 (코드 실행 꺼짐) | 복호화 불가. 질문 본문을 복사용으로 제공하고, 설정에서 코드 실행을 켜도록 안내. |
| 종료코드 `3` (locked) | 부록 A부터 다시. |
| 종료코드 `4` | 설정 파일 손상. 학생에게 스킬 재설치를 안내하고 Wild에게 알리도록 함. |
| 저장된 주소 지우기 | `wild_vault.py forget --skill ask-wild` (시리즈 전체: `--all`). 웹에서는 저장해 둔 접속 토큰(개인 선호, Drive의 `wild-series 접속 토큰` 파일)도 함께 지우도록 안내. |
| 매번 반 암호를 다시 물음 | 부록 A-1의 세 곳(맥락, 과거 대화, Drive)에 토큰이 실제로 있는지 확인. 과거 대화 검색이 꺼져 있으면 A-3의 b 또는 c로 보관 |

교사용 설정·암호 변경 방법은 [TEACHER.md](TEACHER.md).

## 부록 A. 채널 설정 열기 (wild-series 공통)

모든 wild 스킬이 같은 절차를 쓴다. `<skill_dir>`는 이 SKILL.md가 있는 폴더, `<skill>`은 이 스킬의 이름(`ask-wild`)이다.

```bash
python3 <skill_dir>/scripts/wild_vault.py status --config <skill_dir>/config/channels.enc.json --skill ask-wild
```

| `state` | 행동 |
|---|---|
| `ok`, `refreshed`, `series` | 열림. 학생에게 묻지 않는다. (`series`는 다른 wild 스킬에서 이미 입력한 반 암호로 열린 것) |
| `no-cache` | **A-1** 학생용 접속 토큰을 스스로 찾는다 |
| `revoked` | "선생님이 이 반 암호의 사용을 중지하셨어요. 새 암호를 받아 입력해 주세요" → **A-2** |

### A-1. 학생용 접속 토큰 찾기 (학생에게 묻기 전에)

**학생용 접속 토큰**은 학생이 반 암호를 처음 입력했을 때 발급되는 한 줄이다: `WILD-TOKEN v3 <series-id> <token>`.
암호가 아니며, 선생님이 그 반 암호를 회수하면 자동으로 무효가 된다. 시리즈 전체(ask·meet·review·discuss·submit)에서 한 줄로 쓰인다.

아래 순서로 찾고, 처음 찾은 곳에서 멈춘다. **학생에게 아무것도 묻지 않는다.**

1. **현재 맥락**: 학생의 개인 선호 설정, Project 지침·파일, 이번 대화.
2. **과거 대화**: 과거 대화를 검색하는 도구가 있으면 `WILD-TOKEN`으로 검색한다.
3. **학생의 Google Drive**: Drive 검색 도구가 있으면 이름이 `wild-series 접속 토큰`인 파일을 찾아 내용을 읽는다.

찾은 줄(여러 개면 모두)을 stdin으로 넘긴다:

```bash
python3 <skill_dir>/scripts/wild_vault.py token import --config <skill_dir>/config/channels.enc.json --skill ask-wild <<'TOKEN'
WILD-TOKEN v3 <series-id> <token>
TOKEN
```

- 성공 → 열림. 학생에게 "저장된 접속 토큰으로 접속했어요" 한 줄만 알린다.
- 종료코드 `3`(회수됨/무효) 또는 아무 데서도 못 찾음 → **A-2**.

### A-2. 반 암호로 잠금 해제

미리보기의 **학생 안내**에서 이미 받았으면 다시 묻지 않는다. 아니면 학생에게 **"Wild 선생님께 받은 반 비밀키를 입력해 주세요"** 라고 요청하고, stdin으로 넘긴다 (명령행 인자로 넘기지 않는다):

```bash
python3 <skill_dir>/scripts/wild_vault.py unlock --config <skill_dir>/config/channels.enc.json --skill ask-wild <<'PW'
<학생이 입력한 반 암호>
PW
```

- 종료코드 `2`(wrong password): 다시 요청. **3회 실패** 시 중단하고 본문을 복사용으로 주며 "Wild 선생님께 암호를 다시 확인해 주세요"라고 안내.
- 성공 → 열림. 출력의 `"suggest_token": true`이면 **A-3**.
- 처음 연 경우 **부록 B**의 "처음 쓸 때" 안내를 한 번 한다.

### A-3. 접속 토큰 발급과 자동 보관

```bash
python3 <skill_dir>/scripts/wild_vault.py token export --config <skill_dir>/config/channels.enc.json --skill ask-wild
```

**학생이 직접 할 일을 최소화한다.** 아래 a는 항상 하고, b는 가능하면 하고, c는 a·b가 모두 불가능할 때만 한다.

| 방법 | 조건 | 행동 | 학생이 할 일 |
|---|---|---|---|
| **a. 대화 기록에 남기기** | 항상 | 발급된 토큰 줄을 이번 대화에 한 번 보여준다: "학생용 접속 토큰이 발급됐어요. 다음 대화에서는 제가 이 기록을 찾아 자동으로 접속할게요." | 없음 |
| **b. 학생 Drive에 저장** | Drive 파일 생성 도구가 있음 | "다음부터 확실하게 자동 접속되도록, 학생님 Google Drive에 토큰 파일을 저장해 둘까요?" **한 번** 묻고, 동의하면 `wild-series 접속 토큰` 문서를 만든다(내용: 토큰 줄 + 아래 설명). 같은 이름의 파일이 있으면 새로 만들지 않고 내용을 바꾼다. 공유 설정은 바꾸지 않는다 | "네" 한 번 |
| **c. 개인 선호에 붙여넣기** | a의 과거 대화 검색 도구도, b의 Drive 도구도 없음 | "설정 → 프로필 → 개인 선호에 아래 한 줄을 붙여 두면 다음부터 자동으로 접속돼요"라고 안내 | 붙여넣기 한 번 |

c로 넘어가면 **부록 B**에 따라 Google Drive 연결도 함께 안내한다(다음부터 토큰을 자동으로 보관·복원할 수 있다).

토큰 파일·안내에 함께 쓰는 설명: "학생용 접속 토큰입니다. 암호가 아니며, 선생님이 반 암호를 회수하면 자동으로 무효가 됩니다. 다른 사람과 공유하지 마세요."

- 학생이 b나 c를 거절하면 다시 묻지 않는다.
- A-1에서 이미 같은 시리즈의 유효한 토큰을 찾았다면 A-3은 생략한다.
- A-1에서 찾은 토큰이 회수되어 A-2로 새로 발급했다면, b로 저장해 둔 Drive 파일도 새 토큰으로 바꾼다.
- Claude Code(로컬)에서는 `~/.wild-skills` 캐시가 유지되므로 `suggest_token`이 `false`이고 A-3을 하지 않는다.

## 부록 B. 커넥터 연결 안내 (wild-series 공통)

커넥터가 연결돼 있으면 Claude가 확인과 처리를 직접 해서 **학생이 할 일이 줄고 결과가 정확해진다.** 그래서 이 스킬은 필요한 커넥터가 없으면 **항상 연결을 안내**한다.

| 커넥터 | 연결하면 자동으로 되는 것 | 쓰는 스킬 |
|---|---|---|
| **Gmail** | 요청·제출을 학생 메일로 바로 발송 (폼·복사 단계 없음) | 전체 |
| **Google Drive** | 공유 설정 검사, 선생님 계정 자동 공유, 접속 토큰 보관 | submit · review (토큰 보관은 전체) |
| **Google Calendar** | 수업일을 읽어 면담 가능한 시간만 보여줌 | meet |
| **GitHub** | 저장소 공개 여부 확인 | submit · review |

**언제 안내하나**

1. **처음 쓸 때**: 채널 설정을 연 직후(부록 A), 이 스킬이 쓰는 커넥터 중 지금 도구 목록에 없는 것을 한 번에 묶어 알린다.
2. **필요한 순간**: 커넥터가 없어 예비 경로(폼 링크, 학생 확인, 시크릿 창 확인, 수업일 직접 고르기 등)로 넘어갈 때, 그 자리에서 "이 단계는 ○○ 커넥터를 연결하면 자동으로 돼요"라고 한 줄로 알린다.

**규칙**

- 같은 대화에서 같은 커넥터는 **한 번만** 안내한다. 학생이 "나중에"라고 하면 그 대화에서는 다시 말하지 않는다.
- 안내 때문에 진행을 멈추지 않는다. **지금 일은 예비 경로로 계속**하고, 학생이 연결한 뒤 원하면 그 단계부터 다시 한다.
- 연결 여부는 Claude의 도구 목록으로 판단한다. 학생에게 "연결돼 있나요?"를 먼저 묻지 않는다.

**안내 문구** (학생 언어로)

> 이 단계는 **<커넥터>** 를 연결하면 제가 직접 확인해 드릴 수 있어요.
> Claude **설정 → 커넥터**에서 <커넥터>를 연결하고, 대화 입력창의 도구 메뉴에서 켜 두면 돼요. 지금은 다른 방법으로 계속할게요.
