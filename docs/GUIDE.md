# Wild AX Class 스킬 — 학생 가이드

Claude에서 Wild 선생님께 **질문·면담·피드백·토론 주제·과제 제출**을 보낼 때 쓰는 스킬 5종의 설치와 사용법입니다.
스킬이 내용을 정리하고 형식과 링크 공유 설정을 확인해 주므로, 학생은 **하고 싶은 말만** 하면 됩니다.

> 모든 전송은 **학생이 미리보기를 확인하고 "보내기"를 승인한 뒤에만** 일어납니다.

## 1. 한눈에 보기

| 스킬 | 언제 쓰나 | 이렇게 말하면 실행돼요 | 선생님께 가는 것 |
|---|---|---|---|
| **ask-wild** | 공부하다 막혔을 때 | "Wild 선생님께 질문 보내줘" | 주제·시도한 것·막힌 곳·질문 |
| **meet-wild** | 직접 만나 이야기하고 싶을 때 | "Wild 선생님이랑 면담 잡아줘" | 수업일 12:00 / 12:30 / 18:00 중 희망 일시 |
| **review-wild** | 작업 중인 결과물에 의견을 듣고 싶을 때 | "이 초안 피드백 받고 싶어" | 작업물 링크·봐줄 부분·질문 |
| **discuss-wild** | 수업·멘토링에서 다뤄 줬으면 하는 주제가 있을 때 | "이 주제 수업에서 토론하고 싶어" | 주제·내 생각·궁금한 점·원하는 방향 |
| **submit-wild** | 과제 최종본을 낼 때 | "과제 제출해줘" | 제출 링크·AI 사용 내역·제출 시각 |

**헷갈릴 때**: 최종본이면 submit, 아직 작업 중이면 review, 정답이 있는 질문이면 ask, 생각을 나누고 싶으면 discuss입니다.

**"Wild"와 "선생님" 모두 됩니다.** "Wild한테 물어볼래", "선생님께 질문 보내줘" 어느 쪽으로 말해도 스킬이 실행됩니다. 스킬 이름으로 직접 불러도 됩니다(예: `/ask-wild`).

**Claude가 먼저 제안할 수도 있어요.** 같은 대화에서 한 과제나 문제로 여러 번 막히면 "선생님께 질문으로 보내 볼까요?"(ask-wild), 진로나 방향처럼 큰 고민으로 막막해하면 "선생님과 면담을 요청해 볼까요?"(meet-wild)라고 **한 번** 물어봅니다. 원하지 않으면 "아니"라고 하면 되고, 그 대화에서는 다시 묻지 않습니다. 물론 아무것도 승인 없이 보내지 않습니다.

## 3. 설치

### 3-1. claude.ai (웹·데스크톱) — 대부분은 이 방법

1. 이 리포의 [`dist/`](../dist/) 폴더에서 스킬 ZIP 5개를 내려받습니다.
   `ask-wild.zip`, `meet-wild.zip`, `review-wild.zip`, `discuss-wild.zip`, `submit-wild.zip`
2. Claude에서 **사용자 지정(Customize) → 스킬(Skills)** 로 갑니다.
3. **+** → **스킬 만들기** → **스킬 업로드** → ZIP 파일 하나를 선택합니다.
4. 목록에 나타난 스킬이 **켜짐** 상태인지 확인합니다.
5. 5개 모두 같은 방법으로 올립니다.

> 메뉴 이름은 Claude 화면 개편에 따라 조금 다를 수 있습니다(예전 화면: 설정 → 기능 → 스킬).
> ZIP은 **압축을 풀지 말고 그대로** 올립니다. `dist/`의 ZIP은 이미 올바른 형태(폴더째 압축)입니다.

### 3-2. Claude Code

```bash
git clone https://github.com/wild-mental/wild-ax-class-skills.git
mkdir -p ~/.claude/skills
cp -R wild-ax-class-skills/skills/* ~/.claude/skills/
```

### 3-3. 업데이트

선생님이 "스킬을 업데이트하세요"라고 공지하면, 예전 스킬을 지우고 새 ZIP을 같은 방법으로 다시 올립니다(Claude Code는 `git pull` 후 다시 복사).
**설치된 스킬은 저절로 바뀌지 않습니다.** 업데이트해도 반 암호를 다시 입력할 필요는 대부분 없습니다.

## 4. 처음 사용할 때

아무 스킬이나 처음 실행하면 Claude가 순서대로 진행합니다.

1. **반 암호 입력** — 수업에서 받은 암호를 입력합니다. 한 스킬에서 입력하면 **5개 스킬이 모두 열립니다.**
2. **이름과 소속 조 저장** — 소속 조는 있는 경우에만 입력하고, 없으면 제목에 `[개인]`으로 표기됩니다. 한 번 저장하면 다시 묻지 않습니다. 반은 반 암호로 자동으로 정해집니다.
3. **학생용 접속 토큰 발급** — 다음 대화부터 암호를 다시 입력하지 않게 해 주는 한 줄입니다(`WILD-TOKEN v3 …`).
   - Claude가 **대화 기록**에 남기고, Google Drive가 연결돼 있으면 "Drive에 저장할까요?"라고 한 번 묻습니다.
   - 둘 다 안 되는 경우에만 **설정 → 프로필 → 개인 선호**에 그 한 줄을 붙여 넣으라고 안내합니다.
   - 토큰은 **암호가 아니지만 다른 사람과 공유하지 마세요.** 선생님이 반 암호를 바꾸면 자동으로 무효가 되고, 그때 새 암호를 한 번 입력하면 됩니다.

## 5. 연결 도구(커넥터) 설정

커넥터를 연결하면 Claude가 확인과 처리를 **직접** 합니다. 연결하지 않아도 스킬은 동작하지만, 학생이 직접 확인하거나 링크를 눌러야 하는 단계가 생깁니다.

| 커넥터 | 연결하면 | 연결하지 않으면 | 쓰는 스킬 |
|---|---|---|---|
| **Gmail** (강력 권장) | 내 메일로 바로 발송 | 미리 채워진 구글폼 링크나 메일 앱 링크를 눌러 직접 보내야 함 | 전체 |
| **Google Drive** | 공유 설정 자동 확인, 선생님 계정에 자동 공유, 접속 토큰 보관 | 공유 상태를 직접 확인해 알려 줘야 함 | submit · review (토큰 보관은 전체) |
| **Google Calendar** | 수업일을 읽어 면담 가능한 시간만 보여줌 | 공개 수업 캘린더를 보고 수업일을 직접 골라야 함 | meet |
| **GitHub** | 저장소 공개 여부 자동 확인 | 공개 여부를 직접 확인해 알려 줘야 함 | submit · review |

**설정법**

1. Claude **설정 → 커넥터**에서 필요한 커넥터를 **연결**하고 계정 접근을 허용합니다.
2. 대화 입력창의 **도구(🔧) 메뉴**에서 그 커넥터가 **켜져** 있는지 확인합니다.
3. 스킬 사용 중 커넥터가 없으면 Claude가 그 자리에서 한 번 안내합니다. 지금 일은 다른 방법으로 계속 진행되니, 나중에 연결해도 됩니다.

> Gmail 커넥터는 **학생 본인 메일 계정에서** 보냅니다. 보낸 메일은 보낸편지함에 남아 제출 증빙이 됩니다.

## 6. 링크 제출 유형 명세

submit-wild와 review-wild는 링크를 보내기 전에 **선생님이 로그인 없이 열 수 있는지** 검사합니다.
**파일 첨부는 지원하지 않습니다.** 파일은 Google Drive 등에 올리고 링크로 보내세요.

### 통과 기준

| 서비스 | ✅ 통과 | ❌ 불통과 |
|---|---|---|
| **Google Docs·Sheets·Slides·Drive** | 링크가 있는 모든 사용자(뷰어·댓글 작성자·편집자) / Wild 선생님 계정에 직접 공유 / 웹에 게시된 링크 | 제한됨(초대한 사람만) / 특정 조직(학교·회사)만 |
| **Notion** | 웹에 게시된 링크 `…notion.site/…` / Wild 선생님을 페이지에 초대 | 워크스페이스 링크 `notion.so/…`인데 초대하지 않음 |
| **GitHub** | 공개 저장소 / Gist(공개·비밀 모두) / Wild 선생님(`wild-mental`)을 공동 작업자로 초대 | 비공개 저장소인데 초대하지 않음 |
| **그 밖의 서비스** (Figma, Canva 등) | 로그인하지 않은 창(시크릿 창)에서 열림 | 로그인을 요구하거나 접근이 거부됨 |

### 설정법

**Google 문서·드라이브**
- 문서 오른쪽 위 **공유** → **일반 액세스**를 **링크가 있는 모든 사용자**로 → 역할 **뷰어**(review는 **댓글 작성자** 권장) → **링크 복사**.
- **자동 공유**: Google Drive 커넥터가 있으면 Claude가 "선생님 계정에 보기 권한으로 공유해 둘까요?"라고 묻습니다. "네"라고 하면 Claude가 대신 공유합니다(선생님 계정 하나, 보기 권한만).

**Notion**
- 페이지 오른쪽 위 **공유(Share)** → **게시(Publish)** → **웹에 게시** 켜기 → 게시된 `…notion.site/…` 링크를 복사해 제출합니다.
- `notion.so/…` 링크는 로그인이 필요해서 선생님이 열 수 없습니다.

**GitHub**
- 비공개 저장소라면 Claude가 두 가지 중 하나를 고르라고 묻습니다.
  1. **공개로 전환**: 저장소 **Settings → General → Danger Zone → Change repository visibility → Public**. 공개하기 전에 비밀번호·개인정보가 없는지 꼭 확인하세요.
  2. **선생님 초대**: 저장소 **Settings → Collaborators → Add people → `wild-mental`**. 선생님이 **초대를 수락해야** 열리므로, 마감이 가까우면 1번이 더 확실합니다.
- Gist 링크(`gist.github.com/…`)는 바로 통과합니다.

**직접 확인하는 법 (모든 서비스 공통)**
브라우저 **시크릿 창**에 링크를 붙여 넣어, 로그인 없이 내용이 보이면 통과입니다.

## 7. 스킬별 사용 예제

아래 예제의 학생 이름은 `김민준`, 반 라벨은 `ax-wave-2`, 소속은 `2조`입니다. 실제로는 여러분의 이름·반 라벨·소속이 들어갑니다.
**메일 제목 형식**: `[스킬]주제-[반 라벨][소속][이름]` (소속 조가 없으면 `[개인]`으로 표기됩니다)

### 7-1. ask-wild — 질문하기

> **학생**: 프롬프트 체이닝 실습에서 두 번째 단계 출력이 계속 비어 나와. Wild 선생님께 물어볼래.

Claude가 비어 있는 부분(무엇을 시도했는지 등)을 한두 개 묻고 미리보기를 보여줍니다.

```
제목: [ask-wild]프롬프트 체이닝-[ax-wave-2][2조][김민준]

■ 주제: 프롬프트 체이닝 실습
■ 하려던 것 / 시도한 것: 1단계 요약을 2단계 입력으로 넘김. 변수 이름을 바꿔 봄
■ 막힌 지점: 2단계 출력이 매번 빈 문자열
■ 질문: 1단계 출력을 2단계에 넘길 때 형식을 따로 지정해야 하나요?
(반: ax-wave-2 · 소속: 2조)
```

### 7-2. meet-wild — 면담 요청

> **학생**: 프로젝트 방향 때문에 Wild 선생님이랑 면담하고 싶어.

- 수업이 있는 날의 **12:00 / 12:30 / 18:00** 중에서만 고를 수 있고, 면담은 **20분**입니다.
- **최소 6시간 전**에 요청해야 합니다.
- Google Calendar 커넥터가 있으면 Claude가 수업일을 읽어 가능한 시간만 번호로 보여줍니다.

```
제목: [meet-wild]프로젝트 방향-[ax-wave-2][2조][김민준]

■ 희망 일시: 2026-12-09 (수) 12:30–12:50 Asia/Seoul
■ 목적: 과제·프로젝트
■ 방식: 대면
```

선생님이 **답장으로 확정**해야 면담이 잡힙니다. 같은 시간에 요청이 겹치면 다른 시간을 제안받을 수 있습니다.
개인적인 일이라면 메일에는 "개인적인 일로 이야기를 나누고 싶습니다"만 쓰고, 자세한 이야기는 만나서 하세요.

### 7-3. review-wild — 중간 피드백 요청

> **학생**: 이 기획서 초안 Wild 선생님께 피드백 받고 싶어. 링크는 이거야.

- 봐줬으면 하는 부분과 질문은 **각각 최대 3개**입니다. 좁힐수록 좋은 피드백을 받습니다.
- 스스로 생각한 **잘된 점 1개, 아쉬운 점 1개**를 함께 보냅니다.
- 링크 공유 설정을 먼저 검사합니다([6장](#6-링크-제출-유형-명세)).

```
제목: [review-wild]AI 도입 기획서 (초안)-[ax-wave-2][2조][김민준]

■ 작업물: https://docs.google.com/…  (단계: 초안, 공유 설정 ✔)
■ 봐주셨으면 하는 부분: 논리 흐름, 근거
■ 질문: 1) 2장의 ROI 근거가 충분한가요?
■ 스스로 본 점: 잘된 점 – 문제 정의가 분명함 / 아쉬운 점 – 근거 자료가 부족함
■ 지금은 안 보셔도 되는 것: 디자인
```

선생님은 **평균 3일 이내**에 답합니다. 같은 작업물로 **횟수 제한 없이** 다시 요청할 수 있고, 다시 요청할 때는 지난 피드백 이후 바뀐 점을 함께 보냅니다.

### 7-4. discuss-wild — 토론 주제 제안

> **학생**: AI 에이전트한테 어디까지 맡겨도 되는지 수업에서 토론해 보고 싶어.

Claude는 **여러분의 생각을 대신 쓰지 않고**, 질문으로 생각을 끌어냅니다. "아직 정리 중"도 괜찮습니다.

```
제목: [discuss-wild]AI 에이전트 위임의 한계-[ax-wave-2][2조][김민준]

■ 주제: AI 에이전트에게 맡길 수 있는 판단의 범위
```

## 8. 원칙: Claude가 하는 일과 하지 않는 일

| Claude가 하는 일 | Claude가 하지 않는 일 |
|---|---|
| 여러분이 한 말을 정해진 형식으로 정리 | 여러분의 **승인 없이** 보내기 |
| 빠진 정보를 한두 개 질문 | 대화 **원문 전체**를 선생님께 보내기 |
| 링크 공유 설정 검사, 동의 시 선생님 계정에 보기 공유 | 링크를 전체 공개로 바꾸거나 편집 권한 주기 |
| 날짜·시간·파일 이름 규칙 확인 | 과제를 **대신 쓰거나 고치거나 채점**하기 |
| AI 사용 내역을 묻고 그대로 기록 | AI 사용 내역을 추측해서 쓰거나 줄여 쓰기 |

다른 사람의 개인정보나 민감한 사정은 보내지 않도록 Claude가 한 번 확인합니다.
**급하거나 안전이 걱정되는 상황**이라면 메일을 기다리지 말고 가까운 어른이나 상담 기관, 긴급 연락처에 바로 연락하세요. 이 스킬은 긴급 연락 수단이 아닙니다.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 스킬이 실행되지 않음 | 스킬이 **켜짐**인지, **코드 실행**이 켜져 있는지 확인. 또는 "/submit-wild"처럼 스킬 이름을 직접 말해 보기 |
| 업로드가 안 됨 | `dist/`의 ZIP을 **압축 풀지 않고 그대로** 올렸는지 확인 |
| "암호가 틀렸어요" | 수업에서 받은 반 암호를 다시 확인. 3번 틀리면 Claude가 본문만 복사해 주니 선생님께 직접 문의 |
| "이 반 암호의 사용이 중지됐어요" | 선생님이 암호를 바꿨습니다. 새 암호를 받아 한 번 입력 |
| 매번 암호를 다시 물음 | Google Drive 커넥터를 연결하거나, 발급된 접속 토큰 한 줄을 개인 선호에 붙여 넣기 |
| 메일 발송이 안 되고 링크만 줌 | Gmail 커넥터를 연결하면 바로 발송됩니다. 지금은 링크를 눌러 [제출]하면 됩니다 |
| 공유 설정 불통과 | [6장](#6-링크-제출-유형-명세)의 설정법대로 고친 뒤 "다시 확인해줘" |
| 면담 시간이 안 보임 | 6시간 이후의 수업일만 보입니다. 수업일 캘린더가 안 읽히면 링크를 보고 직접 고르세요 |
| 선생님 답장이 없음 | 리뷰는 평균 3일, 면담은 답장으로 확정됩니다. 급하면 수업 시간에 직접 말씀드리세요 |
